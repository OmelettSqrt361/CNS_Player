# CNS_Player

V tomto GitHub repu je uložen celý Unity projekt vyroben v rámci práce "Matematická a počı́tačová analýza hry Člověče, nezlob se a jiných kruhových-křı́žových her", která byla napsána mnou (Jakubem Kuchaříkem) pro soutěž Středoškolská odborná činnost. Pokud si hru chcete zahrát můžete tak učinit na webu https://omeletton.itch.io/clovece-nezlob-se-soc.

Hra byla psána především v jazyce C#. Zkompilovaná je pro prostředí HTML5 proto, aby mohla být spuštěna v prohlížeči. Hra je plně funkční i na mobilních telefonech.

V rámci celého projektu jsou 3 hratelné hry: Aseb; Člověče, nezlob se a Čára. Původně ve hře měla být ještě Královská hra z Uru, ale z důvodů časového tlaku nebyla nidky dokončena. Všechna grafika a počítačový kód v projektu jsou buď soubory Unity (které nemají komerční licenci pro akademické účely) či má vlastní tvorba.
